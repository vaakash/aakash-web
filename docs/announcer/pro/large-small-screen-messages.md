With Announcer - PRO plugin, you can make each announcement fit the screen your visitors are using. You can show one message on larger screens and a different message on smaller screens. The appropriate message appears automatically, so visitors see content that suits their device.

## Add screen-specific messages

1. Open an announcement or create a new one.
2. Place the cursor in the message editor where you want the messages to appear.
3. Select **Add Large/Small Screen Messages**.
4. Enter the message for large screens, then enter the message for small screens.
5. Save or publish your announcement.

You can include HTML in either message to format text or add content. You can also use this feature more than once in an announcement.

## Edit the messages later

To change either message later, edit the announcement and find the screen-specific message in the editor. In the Visual editor, select the message block and use the **Text** tab to edit its shortcode. Update the text between the matching quotes for `large` or `small`, keeping the shortcode structure and quotation marks intact. Then save or update the announcement.

## Make announcements work better for your visitors

Use a shorter message on small screens when space is limited, while keeping more detail on larger screens. You could also change a call to action, highlight different information, or adjust the wording to make an announcement easier to read on each screen.
